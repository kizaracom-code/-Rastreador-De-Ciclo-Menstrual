👑 Painel do dono — só você vê esta barra

Esta é a SUA cópia. A versão da cliente é o arquivo index-cliente.html, sem esta barra. Para vender: mande só o arquivo da cliente. Para testar, use esta cópia à vontade — ela não mistura com a da cliente.

1. No GitHub, crie um repositório e suba o arquivo index-cliente.html renomeado para index.html.
2. Ative Settings > Pages > Deploy from a branch > main / root.
3. O link que o GitHub gerar é o link da cliente. Mande esse link pra ela.
4. Cada cliente abre o link no próprio celular e os dados ficam salvos só no aparelho dela. Nada vem preenchido.
5. Nunca mande este arquivo do dono — ele tem esta barra e é só para você testar e gerenciar.
